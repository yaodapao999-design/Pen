4×4 Bayer Matrix 纹理说明
=========================

如需将 Bayer 矩阵以纹理形式使用，请在 Unity 编辑器中手动创建：

步骤：
1. 在 Project 窗口中右键 → Create → Texture2D（或通过脚本创建）
2. 纹理尺寸：4×4
3. Filter Mode: Point（禁用双线性插值，保持像素精确）
4. Wrap Mode: Repeat（平铺以覆盖整个屏幕）
5. 按下列颜色值（0-255 灰度）填写各像素，保存为 T_BayerMatrix.png 放在此目录下：

行列顺序（行0为顶部，列0为左侧）：
  列: 0    1    2    3
行0: [ 16, 144,  48, 176]
行1: [212,  80, 240, 112]
行2: [ 64, 192,  32, 160]
行3: [208,  96, 224,  64]

归一化值（除以 255）：
  列: 0      1      2      3
行0: [0.063, 0.565, 0.188, 0.690]
行1: [0.831, 0.314, 0.941, 0.439]
行2: [0.251, 0.753, 0.125, 0.627]
行3: [0.816, 0.376, 0.878, 0.251]

注意：
- DitherUtils.hlsl 已使用内联 Bayer 矩阵（static const float 数组），无需纹理采样
- 此说明文件仅作参考，用于需要纹理版本 Bayer 矩阵的场景
- 内联版本性能更优，且避免了纹理采样开销
